Repeat the test when H₀ is true

Use the rail buttons to generate tests when the null hypothesis is true. Each row gives a simulated z-score from the standard normal distribution. A red point means the test rejected a true null hypothesis—a false rejection.

The pale regions show the rejection cutoffs chosen by α and the alternative hypothesis. With many tests, the fraction of false rejections approaches α; a short run will vary. This is not the probability that a particular null hypothesis is true. Changing the test setup starts a fresh run.

Use independent, representative observations. Mean z-procedures require known σ and a normal population or an adequate CLT approximation; n ≥ 30 alone is not a guarantee. Proportion tests require expected null counts np₀ ≥ 10 and n(1 − p₀) ≥ 10; the elementary proportion interval instead checks observed success and failure counts. The proportion test uses SE = √(p0(1 − p0)/n); the proportion CI uses SE = √(p̂(1 − p̂)/n).
