Repeat the test when H₀ is true

Each row is a new simulated standardized statistic from N(0, 1), the reference model used above. Red points are false rejections. The dashed cutoffs and pale rejection regions are fixed by the selected alternative and α. This simulation uses the normal reference model, rather than resampling the entered data.

Over many valid tests with H₀ true, the rejection fraction approaches α. A short run will vary. This rate is not the probability that a particular rejected claim is true. Changing the alternative, α, or null model starts a fresh run.

Use independent, representative observations. Mean z-procedures require known σ and a normal population or an adequate CLT approximation; n ≥ 30 alone is not a guarantee. Proportion tests require expected null counts np₀ ≥ 10 and n(1 − p₀) ≥ 10; the elementary proportion interval instead checks observed success and failure counts. The proportion test uses SE = √(p0(1 − p0)/n); the proportion CI uses SE = √(p̂(1 − p̂)/n).
