Two-Sample Difference Explorer

Draw two independent samples, then estimate the difference between their population means. Watch intervals accumulate and compare coverage of the true difference with a test of equal means.

1. Choose the populations for this simulation

Both populations are normal, and their standard deviations are known. These are specified population parameters for generating data. Every draw takes fresh, independent observations from each group; the groups are not paired.

2. Inspect the latest two samples

Each small dot is one observed value. A diamond marks its group’s sample mean. Vertical jitter separates dots; it has no statistical meaning.

3. Compare the difference with the equality model

The test is two-sided: H₀ says the population difference is 0; Hₐ allows either sign. The curve below is the distribution of the difference under H₀. Dark shading counts results at least as far from 0 as the observed difference. Pale shading marks the prechosen rejection regions.

4. Let the difference intervals pile up

Every row comes from a fresh pair of independent samples. The bar estimates the population difference; the dot is the observed difference. The true value is visible here because we specified the simulation model.

The decision text is red when the test rejects equality. An interval can contain the true difference while excluding zero when the population means differ.

Try a comparison

  1. Start with equal means and draw many sample pairs. Compare the fraction of intervals that miss the true difference with α = 1 − confidence level.
  2. Choose unequal sampling precision. Increase only the smaller, noisier sample. Watch which variance contribution shrinks and how the interval width changes.
  3. Reverse the subtraction order. The same differences and intervals reflect across 0, while two-sided p-values and decisions stay the same.
  4. Change 95% to 99% while keeping the same draws. Intervals widen; the p-values stay fixed, but the rejection threshold changes.

These exact normal-model results use known population SDs. For real data with estimated SDs, use an appropriate method such as Welch’s t procedure. Proportion tests require their own pooled null standard error, as explained in the reading. At an exact interval endpoint, the test’s equality convention and numerical rounding matter.
