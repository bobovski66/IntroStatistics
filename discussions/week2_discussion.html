Case file

The problem

Imagine a small skywatch group that spends several nights monitoring the same patch of sky with two synchronized cameras. Because people can disagree about what counts as “something strange,” the group decides in advance to use a fixed rule. A light is recorded as a qualified anomalous-light event only if it lasts at least 10 seconds, appears to move against the apparent star field, and is captured by both cameras.

This definition is intentionally operational: it tells the observers how to classify what they see, but it does not identify the object or explain its cause. A qualified event could eventually turn out to be an aircraft, satellite, atmospheric effect, unknown object, or something else. For the probability model, all that matters is whether an observation window satisfies the rule.

The group divides the night into consecutive 10-minute observation windows. From earlier nights they build a simplified model in which each window has probability p = 0.18 of containing at least one qualified event. For this exercise, also assume that one window does not affect the next, so the windows may be treated as independent.

Now suppose the group watches eight consecutive windows. There are two natural questions they might ask. One is, “How long will we wait until the first qualified event?” The other is, “How many of the eight windows contain at least one qualified event?” Those questions sound similar, but they define different random variables and therefore lead to different probability models.

For one window, record S if at least one qualified event occurs and F otherwise. Two qualified lights in the same window still produce one S. Define \(T\) as the number of windows through and including the first S; for that question, imagine continuing the same protocol as long as needed. Define \(B\) as the number of S windows among the fixed first eight.

The statistical question: When should we use a geometric model, when should we use a binomial model, and what assumptions are we quietly making when we apply either one to a real observing session?

Initial post

What to include

  1. Using a geometric model, find the probability that the first window containing a qualified event is window 4. State the required S/F prefix.
  2. Find the expected number of windows through and including the first qualified window. Explain why an average wait is not a deadline.
  3. Using a binomial model with n = 8 and p = 0.18, find the probability that exactly two of the eight windows contain at least one qualified event. Identify the combination factor.
  4. Find the expected number of qualified windows among eight. Include the units and explain why a noninteger expected count is allowed.
  5. Explain, in words, why the geometric and binomial questions use the same value of p but model different things. Also identify one assumption in the simplified model that could fail in a real skywatch. For example, one moving light could span adjacent windows or weather could change during the session.
  6. If all eight windows are F, should the waiting time be recorded as T > 8 or T = ∞? Under the stated independent model, is a qualified event more likely in the next window because none has appeared yet?

Replies

Engage with classmates’ statistics

Choose a classmate who organized the two models differently from you. Verify one probability, then explain whether their description of the random variable makes it clear the units and stopping rule of each model. Check that their binomial variable counts positive windows rather than the total number of lights.
