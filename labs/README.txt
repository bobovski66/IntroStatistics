Math 146 Student Lab refresh

Files included:
- Weeks 1–10 student-facing labs
- Both uploaded Week 9 variants (regular guided lab and fireball case-file version)

New common features:
- consistent “How to complete this lab” and “What you’ll practice” sections
- one-line goal at each problem/major section
- sticky student toolbar and problem navigation
- automatic browser saving retained
- completion progress indicator
- Save filled HTML: downloads a portable copy with current answers embedded
- Print / Save PDF
- clearer final submission checklist
- responsive/mobile and print refinements

Important: A filled HTML file is a single HTML document containing the student's current form values. The labs still use MathJax/font CDNs where the originals did, so an internet connection may improve math/font rendering, but entered answers remain embedded in the saved file.
