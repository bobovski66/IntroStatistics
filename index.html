How grading works

  • Weekly module average: 60% of the course grade.
  • Midterm: 15%.
  • Final: 25%.
  • Within a week, the six categories carry equal weight.
  • The current grade uses work that has been started; future untouched weeks are not counted yet.

Course sequence

The course moves from describing samples, through probability and sampling, into estimation, testing, categorical models, applied inference, and regression.

Using this course page

Course Help

Completing weekly work

Open the linked reading, demos, Python lab, and other labs in new tabs. Return here and check “Mark complete” after the work has been finished. The checkboxes are a personal record; the page cannot inspect activity in another tab.

Assessment feedback

Press Check my current answers. Correct questions become locked and are saved. An incorrect response receives a small hint but not the answer. Decimal answers are accepted within a gentle tolerance, so harmless rounding differences will not block progress.

Saving progress

Progress is stored in this browser using local storage. Use Export Progress to create a backup file. Use Import Progress to restore that file on another device or browser.

Privacy and limitations: This static page does not send grades to an instructor or server. A printed or exported grade report can be submitted separately if required.
